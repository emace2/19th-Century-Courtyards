Quick Setup Guide — How to Connect URP

Follow these steps in order. Each step takes under a minute.

#StepWhereNotes
1Open URP ConnectorTools → EmacE → URP ConnectorIf URP is not installed the panel offers a one-click install button.
2Select pipeline assetSection 1 — Graphics SettingsPick the asset matching your target quality (e.g. HighQuality). Use Auto-match by name to fill all quality levels automatically.
3Create Very High assetSection 1 — Quality SettingsClick Ensure Very High Pipeline Asset if the button is visible. Sets optimised shadow distance, cascades and LUT size automatically.
4Click CONNECT URPSection 1 — bottomAssigns the pipeline asset to Graphics Settings and all enabled quality levels. Activates the High level. GUIDs are regenerated if the option is checked.
5Upgrade materialsSection 2 — MaterialsAssign the materials folder and click Upgrade Materials to URP. Unity's built-in converter remaps Standard → URP/Lit shaders.
6Fix terrainSection 3 — TerrainClick Fix Terrain. Creates a URP/Terrain/Lit material per Terrain and assigns it. Save the scene afterwards.
7Connect post-processingSection 4 — Post ProcessingAssign a profile folder. Select an existing profile and click Connect, or choose a climate preset and click Generate. A Global Volume is created if the scene has none. The camera is fixed automatically (Post Processing ON, FXAA).
8Add SSAOSection 5 — Renderer FeaturesSelect the renderer asset and click Add Screen Space Ambient Occlusion. Defaults: Blue Noise, Intensity 3, Depth Normals, High quality.
9Save the sceneFile → Save (Ctrl+S)The Global Volume and camera changes are scene objects — save to keep them.
Health check: The five status dots at the top of the panel (URP · Assets · Volume · Camera PP · SSAO) turn green as each step is completed. All green = fully connected.

6 — Vertex Color Materials

Vertex Color is a technique where colour information is stored directly in the mesh's vertex data instead of a texture. It's commonly used in low-poly, stylised and performance-critical assets — zero texture memory, instant rendering, no UV unwrapping needed.

What it does
FeatureDescription
Auto-detectScans the selected materials folder for any material whose shader name contains VertexColor or VertColor.
One-click conversionSwaps the shader to Custom/URP/VertexColor and transfers _Color → _BaseColor so the tint is preserved.
Auto shader generationIf the URP vertex color shader is missing from the project it is created automatically at Assets/EmacEArt/VertexColorURP.shader — no manual file copying needed.
Lighting supportThe generated shader uses PBR lighting (shadows, ambient, fog) — not flat/unlit. Matches the visual style of URP/Lit materials.
Color tintA Base Color tint property multiplies over vertex colours — useful for global brightness or colour shifts per material.
Requirements — when it works
RequirementDetails
URP installedThe shader uses URP-specific HLSL includes. It will not compile in a Built-in or HDRP project.
Mesh has vertex coloursThe mesh must have vertex colour data baked in (exported from Blender, Maya etc. with vertex colours enabled). If the mesh has no colour data Unity passes white (1,1,1,1) — result looks correct but flat.
Materials folder selectedThe Materials Folder field in the URP Connector window must point to the folder containing the target materials.
Shader name conventionSource materials must use a shader whose name contains VertexColor or VertColor (case-insensitive). Materials already on Custom/URP/VertexColor are skipped.
When it will NOT work
SituationWhy
Mesh uses texture-based colourSwitching to the vertex color shader will drop the texture — albedo becomes black/white.
Shader name doesn't match conventionMaterials with unrecognised shader names are skipped. Rename the shader or assign manually.
No materials folder setThe button is disabled until a folder is selected in the Materials section.
Built-in / HDRP pipelineThe Custom/URP/VertexColor shader requires URP packages to compile.
Tip: After conversion verify in the Scene view that colours look correct. If a material appears too dark, check that the mesh normals are correct — the shader uses PBR ambient (SampleSH) which responds to normal direction. If a material appears white/grey the mesh likely has no vertex colour data baked in.
